## 课程概述

本门机器学习入门课程涵盖该领域的基础概念和算法。通过本课程的学习，学生将能够：

- 理解关键的机器学习范式和概念
- 实现基本的机器学习算法
- 评估和比较模型性能
- 将机器学习技术应用于实际问题

## 先修要求

- 线性代数和微积分的基础知识
- Python 编程经验
- 概率论与数理统计基础

## 教材

- 主教材：《机器学习：一种概率视角》，Kevin Murphy 著
- 参考书：《模式识别与机器学习》，Christopher Bishop 著
