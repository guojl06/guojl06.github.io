## 题目描述

大家都知道，C++中内置的整数类型 int 的精度有限，这会导致某些大整数的运算无法正常进行。本题需要实现一个简单的大整数类，这个大整数类需要具备以下基本功能：

* 能与 int 类型的数据进行加法运算。
* 能与同类的对象进行加法运算。
* 可以进行两种自增运算。
* 可以与 int 类型一样输出。

在 `main.cpp` 中会对大整数类的这些功能进行测试，正确实现上述功能即可得到正确的计算结果。

`main.cpp`:

```
#include "CHugeInt.h"
#include <iostream> 
using namespace std;

int  main() { 
    char s[210];
    int n;

    while (cin >> s >> n) {
        CHugeInt a(s);
        CHugeInt b(n);

        cout << a + b << endl;
        cout << n + a << endl;
        cout << a + n << endl;
        b += n;
        cout  << ++ b << endl;
        cout << b++ << endl;
        cout << b << endl;
    }
    return 0;
}
```

## 输入

多组数据，每组数据是两个非负整数s和 n。s的长度最多可能为200位， n可以用int表示。

## 输出

对每组数据，输出6行，内容对应`main.cpp`中的6个输出语句。
