## 题 1（2023）：直线相交

### ① 题目要求概括
设计**类模板** `Point<T>` 和 `Line<T>`，使 int / double 都能用：
- `Point<T>(x, y)`；接口：`void move(T dx, T dy)`、`void show()` 输出 `(x,y)\n`、`bool check(Line<T> const& l)` 判断点是否在直线上。
- `Line<T>(k)`（`b` 默认 0）或 `Line<T>(k, b)`；接口：`bool intersect(const Line&)`（**重合也算相交**）、`void show()` 输出 `k,b\n`；重载 `operator<` **只比斜率**。
- `x,y,k,b,dx,dy` 同类型；**浮点差值绝对值 < 1e-6 视为相等**。
- 提交 `Line.h / Line.cpp / Point.h / Point.cpp`；main 里写的是 `#include "Line.cpp"` 和 `#include "Point.cpp"`（直接 include .cpp！）。

### ② 完整思路
1. **类模板** 让一套代码同时支持 `int`/`double`。
2. **统一相等判断**：整型用 `==`，浮点用 `fabs(a-b)<1e-6`。最优雅是 `if constexpr (is_floating_point_v<T>)` 编译期分流，避免为 int/double 写两份。
3. **`check` 判点在直线**：`y == k*x + b`（用上面的相等判断）。
4. **`intersect`**：两条直线有交点 ⟺ 斜率不同（必有一个交点）**或** 斜率相同且截距相同（重合）。即 `!eq(k1,k2) || (eq(k1,k2) && eq(b1,b2))`。
5. **`operator<` 只比斜率 `k`**。
6. **致命陷阱——main 直接 `#include "*.cpp"`**：模板不能分离编译，所以**实现必须能被 .cpp 文件拉进来**。最稳：把模板实现**全部 inline 写进 `.h`**，`.cpp` 里只写一行 `#include "xxx.h"`。这样无论 main include 的是 `.h` 还是 `.cpp`，都能拿到完整定义，且不会重复定义（模板 + include guard）。

### ③ 完整代码框架
```cpp
// ============ Line.h ============
#pragma once
#include <iostream>
#include <cmath>
#include <type_traits>

template<class T>
inline bool eq(const T& a, const T& b) {
    if constexpr (std::is_floating_point_v<T>)
        return std::fabs((double)(a - b)) < 1e-6;
    else
        return a == b;
}

template<class T>
class Line {
    T k, b;
public:
    Line(T k, T b = T()) : k(k), b(b) {}            // b 默认 0
    bool intersect(const Line& o) const {
        return !eq(k, o.k) || (eq(k, o.k) && eq(b, o.b));   // 斜率不同 或 重合
    }
    void show() const { std::cout << k << ',' << b << '\n'; }
    bool operator<(const Line& o) const { return k < o.k; } // 只比斜率
    T getK() const { return k; }
    T getB() const { return b; }
};

// ============ Point.h ============
#pragma once
#include <iostream>
#include "Line.h"

template<class T>
class Point {
    T x, y;
public:
    Point(T x = T(), T y = T()) : x(x), y(y) {}
    void move(T dx, T dy) { x += dx; y += dy; }
    void show() const { std::cout << '(' << x << ',' << y << ")\n"; }
    bool check(const Line<T>& l) const {            // y == kx + b
        return eq(y, l.getK() * x + l.getB());
    }
};

// ============ Line.cpp ============
#include "Line.h"      // 只拉头文件，实现已在头里
// ============ Point.cpp ============
#include "Point.h"
```

## 题 2（2023）：图形界面（最难的 40 分大题）

### ① 题目要求概括（4 个递进小问）
- **Q1**：`Widget` 基类已给（`_name`, `Window* _parent`，`getName/getParent/setParent`，虚析构）。实现 `Window`：用 `list<shared_ptr<Widget>>` 存控件；`getPointerByName(name)` 返回 `shared_ptr<Widget>`；`getElementByName(name)` 返回 `Widget&`；`addElement(w)`（**重名返回 false 不添加**，否则 `setParent` 后加入返回 true）。
- **Q2**：实现 `Click`、`DoubleClick` 两个**事件混入基类**；`Button : public Widget, public Click, public DoubleClick`。`setClickCommand(f)` / `setDoubleClickCommand(f)` 接收 `void()` 可调用对象（每次覆盖）；`click()` / `doubleClick()` 执行之（**未设置则什么也不做**）。
- **Q3**：`Checkbox : public Widget, public Click`，有选中/未选中两态（默认未选中），`click()` 默认 **toggle** 选中状态。再写三个**函数对象**：`SelectAll(l)` 把 list 中 checkbox 全选；`ClearAll(l)` 全清空；`Submit(l)` 输出每个 checkbox 的状态（格式 `"c1 is not selected\n"` / `"c1 is selected\n"`）。
- **Q4（40 分）**：`Window::undo()`。**会改变多选框选中情况的操作只有 3 种**：`Checkbox::click`、`SelectAll`、`ClearAll`。每次 `undo()` 撤回**前一次**这种修改；**无论 SelectAll/ClearAll 是否真的改变状态都算一次撤销**；无可撤销返回 `false`，否则撤销并返回 `true`。
- 提交 `window.h / command.h / event.h`（main.cpp / Makefile / 部分头文件由 OJ 提供）。
- 输入指令：`create button/checkbox AA`；`setclick/setdoubleclick AA clear/select/submit m A B C...`；`click/doubleclick XX`；`undo`。

### ② 完整思路（四大设计模式一次用全）
1. **Mixin 多继承**：`Button` 同时继承 `Widget`（身份）+ `Click` + `DoubleClick`（能力）。`Click/DoubleClick` 不持有身份，只提供"事件能力"，是典型 mixin。
2. **Command 模式 + `std::function<void()>`**：`Click` 内部存一个 `std::function<void()>`。`SelectAll/ClearAll/Submit` 是**函数对象 (functor)**，重载 `operator()`，可隐式转为 `std::function<void()>` 传给 `setClickCommand`。这样新增命令类型无需改 `Click` 类——**对扩展开放**。
3. **Memento 模式（undo 核心）**：`Window` 维护一个**快照栈** `vector<vector<char>> history`，每个快照记录"本窗口所有 checkbox 的选中状态"。**在任何会改变状态的操作执行之前**，先 `snapshot()` 存当前状态。`undo()` 弹栈恢复。
   - "无论 SelectAll/ClearAll 是否真改变都算一次" ⟹ **操作前无条件 snapshot**（即使前后状态一样也存一份）。
   - `Submit` 不改状态 ⟹ 不 snapshot。
   - `Checkbox::click` 改状态 ⟹ toggle 前 snapshot。
4. **谁来触发 snapshot？** `Checkbox::click()`（override `Click::click`）在自己 `toggle` 前调 `getParent()->snapshot()`；`SelectAll/ClearAll::operator()` 在改之前通过 `boxes.front()->getParent()->snapshot()` 触发（checkbox 已被 `addElement` 设置了 `_parent`，所以能拿到 Window）。
5. **snapshot 范围**：必须存**窗口里所有 checkbox** 的状态（不只是命令 list 里的），因为 undo 要整体恢复。用 `dynamic_pointer_cast<Checkbox>` 遍历 `Widgets` 收集。

// ============ event.h（Click / DoubleClick 事件混入）============
#pragma once
#include <functional>

class Click {
protected:
    std::function<void()> clickCmd;            // 默认为空
public:
    void setClickCommand(std::function<void()> f) { clickCmd = f; }   // 覆盖
    virtual void click() { if (clickCmd) clickCmd(); }                // 未设置则什么也不做
    virtual ~Click() {}
};

class DoubleClick {
protected:
    std::function<void()> doubleClickCmd;
public:
    void setDoubleClickCommand(std::function<void()> f) { doubleClickCmd = f; }
    virtual void doubleClick() { if (doubleClickCmd) doubleClickCmd(); }
    virtual ~DoubleClick() {}
};

// ============ window.h（Widget / Window / Checkbox / Button）============
#pragma once
#include <list>
#include <memory>
#include <string>
#include <vector>
#include "event.h"

class Window;   // 前置，供 Widget 成员使用

class Widget {                       // 题目已给，这里复述
    std::string _name;
    Window* _parent;
public:
    Widget(std::string name) : _name(name), _parent(nullptr) {}
    std::string getName() const { return _name; }
    Window* getParent() const { return _parent; }
    void setParent(Window* p) { _parent = p; }
    virtual ~Widget() {}
};

class Checkbox;   // 前置

class Window {
    std::list<std::shared_ptr<Widget>> Widgets;
    std::vector<std::vector<char>> history;     // Memento 快照栈
    std::vector<char> currentSnapshot();        // 收集所有 checkbox 当前选中态
    void restore(const std::vector<char>& snap);
public:
    std::shared_ptr<Widget> getPointerByName(std::string name);
    Widget& getElementByName(std::string name);
    bool addElement(std::shared_ptr<Widget> w);
    void snapshot();                            // 改状态前调用
    bool undo();                                // 弹栈恢复
};

class Checkbox : public Widget, public Click {
    bool selected = false;
public:
    Checkbox(std::string name) : Widget(name) {}
    void click() override;                      // toggle + 先 snapshot（定义在后面）
    bool isSelected() const { return selected; }
    void setSelected(bool s) { selected = s; }  // SelectAll/ClearAll/restore 用
};

class Button : public Widget, public Click, public DoubleClick {
public:
    Button(std::string name) : Widget(name) {}
};

// ---- Window 方法定义（放在 Checkbox 之后，因为要用 dynamic_pointer_cast<Checkbox>）----
inline std::vector<char> Window::currentSnapshot() {
    std::vector<char> snap;
    for (auto& w : Widgets)
        if (auto c = std::dynamic_pointer_cast<Checkbox>(w))
            snap.push_back(c->isSelected() ? 1 : 0);
    return snap;
}
inline void Window::restore(const std::vector<char>& snap) {
    int i = 0;
    for (auto& w : Widgets)
        if (auto c = std::dynamic_pointer_cast<Checkbox>(w))
            c->setSelected(snap[i++]);
}
inline void Window::snapshot() { history.push_back(currentSnapshot()); }
inline bool Window::undo() {
    if (history.empty()) return false;
    restore(history.back());
    history.pop_back();
    return true;
}
inline bool Window::addElement(std::shared_ptr<Widget> w) {
    if (getPointerByName(w->getName())) return false;   // 重名
    w->setParent(this);
    Widgets.push_back(w);
    return true;
}
inline std::shared_ptr<Widget> Window::getPointerByName(std::string name) {
    for (auto& w : Widgets) if (w->getName() == name) return w;
    return nullptr;
}
inline Widget& Window::getElementByName(std::string name) {
    return *getPointerByName(name);
}
inline void Checkbox::click() {                 // 改状态前先快照
    if (getParent()) getParent()->snapshot();
    selected = !selected;
}

## 题 3（2023）：多级字典

### ① 题目要求概括（4 个递进子任务，不捆绑测试）
- **子1（20）**：`template<class Key,class Value> class MyDict`。`operator[](key)`：命中返回引用；缺失用 `Value()` 初始化并返回。`hitStats()` 返回 `HitStatsResult(hit,miss)`（已实现类）。`size()`、`clear()`（清键值对+清统计）。
- **子2（30）**：`PopStrategy` 基类 + `FIFOStrategy` / `LRUStrategy`。接口 `visit(key)`、`pop()`（保证 pop 时非空）。**"键只在首次访问或被移除后首次访问时视作插入"**。`N≤32`，`O(N)` 即可。FIFO 弹最早插入；LRU 弹最久未访问。
- **子3（20）**：`MyDict()` 无容量限制；`MyDict(int capacity, PopStrategy<Key>* popStrategyPtr)`。`operator[]` 后若超容，用 strategy 选一个 key 弹出。**超容只可能在 `operator[]` 后发生**。
- **子4（30）**：`MyDict(int capacity, PopStrategy<Key>*, MyDict* nextLevelPtr)`。`operator[]`：本级命中直接返回；本级缺失→递归下一级 `[]`，找到后**把键值对从子级弹出插入本级**，再检查本级是否超容，超容则**再弹一个递归插入下一级**（链式传递）。`hitStats()` 返回**所有层级**命中/缺失（`HitStatsResult(vector,vector)`，可用 `+` 拼接）。`size()`=本级+所有子级；`clear()` 清本级+所有子级+统计。
- 提交 `MyDict.hpp` + `PopStrategy.hpp`。有宏 `__SUBTASK1__..__SUBTASK4__`（非必需）。

### ② 完整思路
1. **子1**：底层 `std::map<Key,Value>` + `hit/miss` 两个计数器。`operator[]` 用 `map.find`，命中 `hit++` 返回；缺失 `miss++`，`map[k]=Value()` 返回。
2. **子2（策略模式）**：`PopStrategy` 抽象基类 + 两个派生。FIFO 用 `std::list` 队列 + `std::set` 判存在（`visit` 已存在不重复入队；`pop` 取队首）。LRU 用 `std::list`，`visit` 先 `remove(k)` 再 `push_back(k)`（移到最新），`pop` 取队首（最久未用）。`O(N)` 足够。
3. **子3**：`operator[]` 中**每次访问都要 `strat->visit(key)`**（保证 strategy 与字典内容一致），插入后调 `overflow()`：若 `size>cap`，`strat->pop()` 拿到 key，从 map 删除。
4. **子4（递归 + 链式搬移）**：
   - 本级 `find` 命中 → `hit++` 返回。
   - 本级缺失 → `miss++`：
     - **无下一级** → 插默认值，`visit`，`overflow`，返回。
     - **有下一级** → `Value tmp = (*next)[k]`（递归；返回后 key 必在子级）→ `next->erase(k)`（从子级弹出）→ 本级插入并赋值、`visit`、`overflow()`。`overflow()` 弹出的 key 再用 `(*next)[k]=v` **递归塞回子级**，形成链式传递。
   - `hitStats/size/clear` 都沿 `next` 链递归累加。
5. **返回引用的技巧**：递归时先用临时变量拷贝子级的值，erase 子级后再插入本级，最后返回本级 `map[k]` 的引用。

### ③ 完整代码框架
```cpp
// ============ PopStrategy.hpp ============
#pragma once
#include <list>
#include <set>

template<class Key>
class PopStrategy {
public:
    virtual void visit(const Key&) = 0;
    virtual Key  pop() = 0;
    virtual ~PopStrategy() {}
};

template<class Key>
class FIFOStrategy : public PopStrategy<Key> {
    std::list<Key> q;
    std::set<Key>  exist;          // 判是否已在队列
public:
    void visit(const Key& k) override {
        if (!exist.count(k)) { q.push_back(k); exist.insert(k); }   // 仅首次/弹出后首次视作插入
    }
    Key pop() override {
        Key k = q.front(); q.pop_front(); exist.erase(k); return k;
    }
};

template<class Key>
class LRUStrategy : public PopStrategy<Key> {
    std::list<Key> q;              // 队首=最久未用，队尾=最近访问
public:
    void visit(const Key& k) override { q.remove(k); q.push_back(k); }  // O(N)，移到最新
    Key  pop() override            { Key k = q.front(); q.pop_front(); return k; }
};
```
```cpp
// ============ MyDict.hpp ============
#pragma once
#include <map>
#include <vector>
#include "PopStrategy.hpp"
// 假设 HitStatsResult 已由 OJ 提供：HitStatsResult(long,long) 与 HitStatsResult(vector<long>,vector<long>)，并支持 operator+

template<class Key, class Value>
class MyDict {
    std::map<Key, Value> data;
    long hit = 0, miss = 0;
    int   cap = -1;                       // -1 表示无限制
    PopStrategy<Key>* strat = nullptr;
    MyDict* next = nullptr;

    void overflow() {                     // 本级超容则弹一个到下一级（链式）
        if (cap < 0 || !strat) return;
        while ((int)data.size() > cap) {
            Key k = strat->pop();
            Value v = data[k];
            data.erase(data.find(k));
            if (next) (*next)[k] = std::move(v);   // 递归插入下一级
        }
    }
public:
    MyDict() {}
    MyDict(int c, PopStrategy<Key>* s) : cap(c), strat(s) {}
    MyDict(int c, PopStrategy<Key>* s, MyDict* n) : cap(c), strat(s), next(n) {}

    void erase(const Key& k) { auto it = data.find(k); if (it != data.end()) data.erase(it); }
    bool count(const Key& k) const { return data.count(k); }

    Value& operator[](const Key& k) {
        auto it = data.find(k);
        if (it != data.end()) { ++hit; return it->second; }      // 本级命中
        ++miss;
        if (!next) {                                             // 无下一级：插默认值
            if (strat) strat->visit(k);
            Value& ref = data[k];
            overflow();
            return ref;
        }
        Value tmp = (*next)[k];          // 递归下一级；返回后 k 必在子级
        next->erase(k);                  // 从子级弹出
        if (strat) strat->visit(k);
        Value& ref = data[k];
        ref = std::move(tmp);
        overflow();                      // 可能链式把别的 key 塞回子级
        return ref;
    }

    HitStatsResult hitStats() const {
        if (!next) return HitStatsResult(hit, miss);             // 子1/3：单级用标量构造
        std::vector<long> h{hit}, m{miss};                       // 子4：沿 next 链收集所有级
        for (MyDict* p = next; p; p = p->next) { h.push_back(p->hit); m.push_back(p->miss); }
        return HitStatsResult(h, m);
    }
    long size() const {
        long s = (long)data.size();
        if (next) s += next->size();
        return s;
    }
    void clear() {
        data.clear(); hit = miss = 0;
        if (next) next->clear();
    }
};
```

### ④ 陷阱
- LRU 的 `visit` 要先删后插（移到队尾）；FIFO 的 `visit` 已存在不重复入队。
- 多级 `operator[]` 返回的是**本级**引用，递归中用临时变量搬运。
- `overflow()` 用 `while` 循环（一次 `[]` 可能触发多次弹出）。
- `hitStats` 单级返回标量构造、多级返回 vector 构造（按 `next` 是否存在分流）。

## 题 5（2024）：简化的文本编辑器

### ① 题目要求概括
实现 `TextEditor`，文本为多行，字符位置 `(row,col)`，光标 `(row,col)` 表示**在该位置字符之前**：
- **构造**：文本空（表现为一个空行），光标 `(0,0)`，非选中。
- **MOVE row col**：移动光标，越界移到**最近边界**（先 clamp row 再 clamp col）。
- **WRITE data**：光标处写入字符串，光标移到**写入末尾**。
- **NEWLINE**：光标所在行**下方**插入新行，光标之后的字符移到新行，光标到**新行首**。
- **DELETE**：删除光标**前**一个字符，光标位置不变；光标在行首时删上一行换行符并**合并两行**；光标在 `(0,0)` 则**无操作**。
- **UNDO**：撤销最近一次**编辑类操作**（WRITE/NEWLINE/DELETE），文本和光标都恢复（**MOVE 不算编辑、不入栈**）；可多次 UNDO（需记录全部历史）。
- **SCREEN**：输出 `### SCREENSHOT BEGIN ###`、逐行文本（用 `*` 标光标）、`### SCREENSHOT END ###`。初始态输出一个只有 `*` 的空行。
- `m≤200`，写入串长 ≤20，不要求复杂度。提交 `editor.h / editor.cpp`。

### ② 完整思路
1. **数据结构**：`std::vector<std::string> lines`（每行不含 `\n`）+ 光标 `(row,col)`。初始 `lines = {""}`。
2. **MOVE**：`row = clamp(row, 0, lines.size()-1)`，`col = clamp(col, 0, lines[row].size())`。**先 row 后 col**（row 改变后 col 范围才正确）。
3. **WRITE**：`lines[row].insert(col, s); col += s.size();`
4. **NEWLINE**：把 `lines[row]` 在 `col` 处切成 `left/right`，`lines[row]=left`，在 `row+1` 插入 `right`，光标 `(row+1, 0)`。
5. **DELETE**：`(0,0)` 直接 return；`col>0` 删 `lines[row][col-1]` 并 `col--`；`col==0` 把本行拼到上一行末尾（`col` 先记为 `lines[row-1].size()`），删除本行，`row--`。
6. **UNDO（Memento）**：每次**编辑操作前** push 一份 `(lines, row, col)` 快照到历史栈；UNDO pop 恢复。MOVE 不 push。数据极小，朴素拷贝整个 `vector<string>` 完全够。
7. **SCREEN**：逐行，每个位置 `i∈[0, lines[r].size()]`，若 `(r,i)==光标` 先输出 `*`，再输出 `lines[r][i]`（若 `i<size`）；行末输出 `\n`。

### ③ 完整代码框架
```cpp
// ============ editor.h ============
#pragma once
#include <vector>
#include <string>

class TextEditor {
    std::vector<std::string> lines{"",};           // 初始一个空行
    int row = 0, col = 0;
    std::vector<std::pair<std::vector<std::string>, std::pair<int,int>>> hist;  // 快照栈
    void push() { hist.emplace_back(lines, std::make_pair(row, col)); }
    void clamp() {                                 // 先 row 后 col
        if (row < 0) row = 0;
        if (row >= (int)lines.size()) row = (int)lines.size() - 1;
        if (col < 0) col = 0;
        if (col > (int)lines[row].size()) col = (int)lines[row].size();
    }
public:
    void MOVE(int r, int c) { row = r; col = c; clamp(); }       // 不入栈

    void WRITE(const std::string& s) {
        push();
        lines[row].insert(col, s);
        col += (int)s.size();
    }
    void NEWLINE() {
        push();
        std::string right = lines[row].substr(col);
        lines[row].erase(col);
        lines.insert(lines.begin() + row + 1, right);
        ++row; col = 0;
    }
    void DELETE() {
        if (row == 0 && col == 0) return;          // 无操作
        push();
        if (col > 0) {
            lines[row].erase(col - 1, 1);
            --col;
        } else {                                   // 合并到上一行
            col = (int)lines[row - 1].size();
            lines[row - 1] += lines[row];
            lines.erase(lines.begin() + row);
            --row;
        }
    }
    void UNDO() {
        if (hist.empty()) return;
        lines = hist.back().first;
        row  = hist.back().second.first;
        col  = hist.back().second.second;
        hist.pop_back();
    }
    void SCREEN() const {
        std::cout << "### SCREENSHOT BEGIN ###\n";
        for (int r = 0; r < (int)lines.size(); ++r) {
            const std::string& L = lines[r];
            for (int i = 0; i <= (int)L.size(); ++i) {
                if (r == row && i == col) std::cout << '*';
                if (i < (int)L.size()) std::cout << L[i];
            }
            std::cout << '\n';
        }
        std::cout << "### SCREENSHOT END ###\n";
    }
};
```

### ④ 陷阱
- **MOVE 不入 undo 栈**（只有编辑操作才记录）。
- DELETE 的"行首合并"：先把光标列设为上一行原长，再拼接、删行。
- SCREEN 中 `*` 在光标字符**之前**；空行也要输出 `*`（初始态）。
- clamp 必须**先 row 后 col**。

## 题 6（2024）：计算图（自动微分，最优雅）

### ① 题目要求概括
实现简单计算图框架，支持自动微分（反向传播）：
- `Node`（非叶节点/算子）：`float get_val()`（正向计算值）；`void backward(float g)`（给定本节点梯度，按算子类型向输入传播）。算法在**结果节点**调用 `backward(1.0)`。
- `LeafNode`（叶节点/变量，接口已给）：累加所有传播到它的梯度。
- 重载 `+ - * /` 把节点组合成新节点。
- 四算子反向规则（`g` 为本节点梯度）：
  - `y=a+b`：`a←g`，`b←g`
  - `y=a-b`：`a←g`，`b←-g`
  - `y=a*b`：`a←g·b`，`b←g·a`
  - `y=a/b`：`a←g/b`，`b←-g·a/b²`
- **不允许内存泄漏**（测试点 8、9 检查）。提示：`LeafNode→Node` 隐式转换；`Node` 设计成**包装器**（内部指针指向真正算子实现多态）；可用智能指针但要**避免误删 LeafNode**。
- 提交 `leaf_node.h/cpp`、`node.h/cpp`。

### ② 完整思路
1. **包装器模式 + 多态**：抽象基类 `NodeBase`（纯虚 `get_val/backward`）；算子节点（`AddNode/SubNode/MulNode/DivNode`）派生；`Node` 是**包装器**，内部持 `shared_ptr<NodeBase>`，把调用转发给内部指针。这样 `Node` 之间做 `+ - * /` 时虽然不是指针形态，仍能通过内部指针实现多态——**这是题目提示的核心**。
2. **`LeafNode → Node` 隐式转换 + 空 deleter**：LeafNode 常是**栈对象**（`LeafNode a(3.0);`）。若用普通 `shared_ptr` 管理它，析构会 `delete` 栈对象 → 崩溃。解决：构造一个**空 deleter** 的 `shared_ptr`（`shared_ptr<NodeBase>(ptr, [](NodeBase*){})`），只引用不释放。算子节点是 `make_shared` 堆对象，正常管理。
3. **forward**：`get_val()` 递归求值（规模小，重复算可接受）。
4. **backward**：从结果节点 `backward(1.0)`，按算子规则把梯度传给两个输入；`LeafNode::backward` 累加 `grad`。
5. **四算子梯度公式必须背熟**（见上）。乘除用 forward 时算出的输入值 `a_val/b_val`。

### ③ 完整代码框架
```cpp
// ============ leaf_node.h ============
#pragma once
#include <memory>

struct NodeBase {                                  // 抽象基类（多态核心）
    virtual float get_val() const = 0;
    virtual void  backward(float g) = 0;
    virtual ~NodeBase() {}
};

class LeafNode : public NodeBase {                 // 叶节点（题目已给接口，这里复述）
    float val;
    float grad = 0;
public:
    LeafNode(float v) : val(v) {}
    float get_val() const override { return val; }
    void  backward(float g) override { grad += g; }   // 叶节点：累加梯度
    float get_grad() const { return grad; }
};
```
```cpp
// ============ node.h ============
#pragma once
#include <memory>
#include "leaf_node.h"

// ---- 四种算子节点（内部 shared_ptr<NodeBase> 指向输入）----
class AddNode : public NodeBase {
    std::shared_ptr<NodeBase> a, b;
public:
    AddNode(std::shared_ptr<NodeBase> x, std::shared_ptr<NodeBase> y) : a(x), b(y) {}
    float get_val() const override { return a->get_val() + b->get_val(); }
    void  backward(float g) override { a->backward(g);          b->backward(g); }
};
class SubNode : public NodeBase {
    std::shared_ptr<NodeBase> a, b;
public:
    SubNode(std::shared_ptr<NodeBase> x, std::shared_ptr<NodeBase> y) : a(x), b(y) {}
    float get_val() const override { return a->get_val() - b->get_val(); }
    void  backward(float g) override { a->backward(g);          b->backward(-g); }
};
class MulNode : public NodeBase {
    std::shared_ptr<NodeBase> a, b;
public:
    MulNode(std::shared_ptr<NodeBase> x, std::shared_ptr<NodeBase> y) : a(x), b(y) {}
    float get_val() const override { return a->get_val() * b->get_val(); }
    void  backward(float g) override {
        float av = a->get_val(), bv = b->get_val();
        a->backward(g * bv);      b->backward(g * av);
    }
};
class DivNode : public NodeBase {
    std::shared_ptr<NodeBase> a, b;
public:
    DivNode(std::shared_ptr<NodeBase> x, std::shared_ptr<NodeBase> y) : a(x), b(y) {}
    float get_val() const override { return a->get_val() / b->get_val(); }
    void  backward(float g) override {
        float av = a->get_val(), bv = b->get_val();
        a->backward(g / bv);      b->backward(-g * av / (bv * bv));
    }
};

// ---- Node 包装器 ----
class Node {
    std::shared_ptr<NodeBase> p;
public:
    Node(std::shared_ptr<NodeBase> q) : p(q) {}
    // LeafNode（栈对象）→ Node：空 deleter 防误删
    Node(const LeafNode& l)
        : p(std::shared_ptr<NodeBase>(const_cast<LeafNode*>(&l), [](NodeBase*){})) {}

    float get_val() const            { return p->get_val(); }
    void  backward(float g = 1.0f)   { p->backward(g); }
    const std::shared_ptr<NodeBase>& impl() const { return p; }
};

inline Node operator+(const Node& x, const Node& y) { return Node(std::make_shared<AddNode>(x.impl(), y.impl())); }
inline Node operator-(const Node& x, const Node& y) { return Node(std::make_shared<SubNode>(x.impl(), y.impl())); }
inline Node operator*(const Node& x, const Node& y) { return Node(std::make_shared<MulNode>(x.impl(), y.impl())); }
inline Node operator/(const Node& x, const Node& y) { return Node(std::make_shared<DivNode>(x.impl(), y.impl())); }
```

### ④ 陷阱
- **空 deleter** 是防"智能指针误删栈上 LeafNode"的关键，也是无内存泄漏的关键。
- `Node b = a;`（a 是 LeafNode）后 `b = b + c`：新算子节点持 `b.impl()`（指向 a 的空 deleter shared_ptr 的拷贝），a 不会被删。
- backward 用 forward 值（`a->get_val()`），不要用梯度本身。
- 题目保证 `backward` 调用时涉及的 LeafNode 都还活着（非法代码不会出现）。

- **子3 迭代器（20）**：`Iterator` 支持 `*`、前后缀 `++`、`==`、`=`、`!=`；`begin()`/`end()`。
- **子4 下标访问（20）**：支持 `A[i][j][k]` 链式下标，既能 `A[1][1]=10` 又能 `cout<<A[1][1]`。提示：**赋值与流运算需要值具有不同类型，需两版 `[]` 重载**。
- **子5 维度变换（20）**：`reshape(dims)`（元素不变改维度；**积不同则忽略**）；`resize(dims)`（对应下标存在则保留原值，否则 `T()` 初始化）。**无内存泄漏**。

### ② 完整思路
1. **存储**：`std::vector<T> data` + `std::vector<int> dims(N)`，**行优先 (row-major)** 一维展开。`offset(idx) = Σ idx[i] * stride[i]`，用滚动累乘 `off = off*dims[i] + idx[i]`。
2. **构造边界**：`data` 空→`data.assign(total, T())`；`dims` 空→`dims[0]=data.size()`，其余 1；`dims` 长度<L N→补 1。
3. **`==`**：先比 `dims` 再逐元素比 `data`。`=`：逐元素拷贝。`<<`：按一维下标 0..total-1，把每个线性下标反展开成 N 维 `[i][j][k]`。
4. **迭代器**：内部持 `MultiArray*` + 线性 `index`；`*` 返回 `data[index]`；`++` 线性递增；`begin` index=0，`end` index=total。
5. **多维 `[]`（代理模式，难点）**：用**模板递归代理** `Proxy<R>`（`R`=剩余维数）。`MultiArray::operator[](k)` 返回 `Proxy<N-1>`（记录基地址偏移）；`Proxy<R>::operator[](k)` 返回 `Proxy<R-1>`；`Proxy<0>` 可隐式转为 `T&`。**赋值用非 const 代理（返回 `T&`），流输出用 const 代理（返回可读）**——故需 const/非 const 两套。
6. **reshape/resize**：`reshape` 只改 `dims`（`data` 不动），积不同则不动；`resize` 改 `dims` 并按"线性下标对应"保留旧值（线性下标 < min(旧 total, 新 total) 保留，其余 `T()`）。
7. **内存**：用 `vector` 成员天然不泄漏；若自定义析构/拷贝则遵循 **Rule of Five**。

### ③ 完整代码框架
```cpp
// ============ array.h ============
#pragma once
#include <vector>
#include <iostream>

template<class T, int N>
class MultiArray {
    std::vector<T>   data;
    std::vector<int> dims;              // 长度 N

    int totalSize() const { int t = 1; for (int d : dims) t *= d; return t; }
    int offset(const std::vector<int>& idx) const {     // row-major
        int off = 0;
        for (int i = 0; i < N; ++i) off = off * dims[i] + idx[i];
        return off;
    }
public:
    // ---- 子1 ----
    MultiArray() : dims(N, 0) {}
    MultiArray(const std::vector<int>& d, const std::vector<T>& v = {}) {
        dims.assign(N, 1);
        if (d.empty() && !v.empty()) dims[0] = (int)v.size();          // dims 空：第0维=data长度
        else for (int i = 0; i < (int)d.size() && i < N; ++i) dims[i] = d[i]; // 缺省维=1
        int total = totalSize();
        if (v.empty()) data.assign(total, T());                         // data 空→T()
        else           data = v;                                       // 保证 v.size()==total
    }
    void set(const std::vector<int>& idx, const T& v) { data[offset(idx)] = v; }
    T&   get(const std::vector<int>& idx)             { return data[offset(idx)]; }
    std::vector<int>& get_dims() { return dims; }

    // ---- 子2 ----
    bool operator==(const MultiArray& o) const {
        return dims == o.dims && data == o.data;
    }
    bool operator!=(const MultiArray& o) const { return !(*this == o); }
    MultiArray& operator=(const MultiArray& o) { data = o.data; return *this; } // 同维
    friend std::ostream& operator<<(std::ostream& os, const MultiArray& a) {
        for (int linear = 0; linear < (int)a.data.size(); ++linear) {
            int t = linear; std::vector<int> idx(N);
            for (int i = N - 1; i >= 0; --i) { idx[i] = t % a.dims[i]; t /= a.dims[i]; }
            for (int i = 0; i < N; ++i) os << '[' << idx[i] << ']';
            os << " = " << a.data[linear];
            if (linear + 1 < (int)a.data.size()) os << '\n';            // 最后无回车
        }
        return os;
    }

    // ---- 子3 迭代器 ----
    class Iterator {
        MultiArray* a; int idx;
    public:
        Iterator(MultiArray* a, int i) : a(a), idx(i) {}
        T&  operator*()                  { return a->data[idx]; }
        Iterator& operator++()           { ++idx; return *this; }       // 前缀
        Iterator  operator++(int)        { Iterator t = *this; ++idx; return t; } // 后缀
        bool operator==(const Iterator& o) const { return idx == o.idx; }
        bool operator!=(const Iterator& o) const { return idx != o.idx; }
        Iterator& operator=(const Iterator& o) { a = o.a; idx = o.idx; return *this; }
    };
    Iterator begin() { return Iterator(this, 0); }
    Iterator end()   { return Iterator(this, (int)data.size()); }

    // ---- 子4 多维 []（代理模式，模板递归；这里给出非 const 写入版）----
    // Proxy<Remain>：剩余 Remain 维。Remain=1 时 operator[] 返回 T&
    template<int R> struct Proxy {
        MultiArray* a; int off;
        auto operator[](int k) { return typename Proxy<R-1>::type... ; } // 见说明
    };
    // 简化版（仅示意）：用平面偏移 + 记录已下钻层数
    struct Sub {
        MultiArray* a; int off; int depth;
        Sub operator[](int k) { return Sub{a, off * a->dims[depth] + k, depth + 1}; }
        operator T&() { return a->data[off]; }                  // depth==N 时转 T&（赋值用）
    };
    struct CSub {                                               // const 版（流输出用）
        const MultiArray* a; int off; int depth;
        CSub operator[](int k) const { return CSub{a, off * a->dims[depth] + k, depth + 1}; }
        operator const T&() const { return a->data[off]; }
    };
    Sub  operator[](int k)       { return Sub{this, k, 1}; }
    CSub operator[](int k) const { return CSub{this, k, 1}; }

    // ---- 子5 ----
    void reshape(const std::vector<int>& d) {                  // 积不同则忽略
        int t = 1; for (int x : d) t *= x;
        if (t == totalSize()) { for (int i = 0; i < N; ++i) dims[i] = d[i]; }
    }
    void resize(const std::vector<int>& d) {                   // 线性下标对应：保留或 T()
        std::vector<int> nd = d; std::vector<T> ndata;
        int nt = 1; for (int x : nd) nt *= x;
        ndata.reserve(nt);
        for (int i = 0; i < nt; ++i) ndata.push_back(i < (int)data.size() ? data[i] : T());
        dims = nd; data = std::move(ndata);
    }
};
```
> **子4 的代理**：核心是"链式 `[]` 每层把当前偏移 `off = off*dims[depth] + k`，下钻一层；最后一层（`depth==N`）`off` 即线性下标，`operator T&()` 返回元素引用"。`Sub`（非 const，支持 `A[1][1]=10`）与 `CSub`（const，支持 `cout<<A[1][1]`）两个版本，对应提示"两版 `[]` 重载"。完整实现还需对 `Sub/CSub` 在 `depth==N` 时才允许转 `T&`（可用 `if constexpr` 或特化）。

### ④ 陷阱
- `<<` 最后**无回车**，元素间才换行。
- `reshape` 积不同**整个忽略**（不报错，不改）。
- `resize` 按**线性下标**对应保留（不是按 N 维下标）。
- 多维 `[]` 必须给 **const + 非 const 两套**（读/写区分）。
- 内存：用 `vector` 即可，避免裸指针。

## 题 9（2025）：草莓巧克力

### ① 题目要求概括
`n` 只巧克力（编号 `0..n-1`）+ `m` 只草莓（编号 `n..n+m-1`），统称"草莓巧克力"。心情值初始全 0。三种活动：
- **op0 x y**（逛动物园）、**op1 x y**（逛商场）、**op2 x**（x 过生日）。
- **心情增量规则**：
  - 逛动物园：巧克力 +5；草莓 +1；**草莓的同伴是巧克力时，该草莓再 +5**。
  - 逛商场：巧克力 +1；草莓 +5；**草莓的同伴是巧克力时，该草莓再 +5**。
  - 过生日：巧克力 +1，若邀请了来宾再 +5；草莓 += 邀请来宾数 k。
  - **被邀请参加生日者：+1**。
- **邀请规则**：
  - 巧克力过生日：邀请"**最后一次和它逛动物园的草莓巧克力**"（任意类型；从未逛过则不邀请）。
  - 草莓过生日：邀请"**所有曾和它逛商场的草莓巧克力**"（任意类型）。
- **关键**："草莓巧克力"是**种族统称**，含草莓和巧克力两类，所以**巧克力也能被草莓邀请、巧克力生日可邀请巧克力**。
- `event.h` 已实现活动接口，写 `strawchoco.h / strawchoco.cpp` 实现 `Strawberry` 与 `Chocolate`。`n,m,l≤1000`。提交 `strawchoco.h / strawchoco.cpp`。

### ② 完整思路
1. **"草莓巧克力"是统称** → 两种类有**共同基类** `StrawChoco`，提供 `isStraw()` 区分类型。心情计算逻辑放在基类，按 `isStraw()` 分流。
2. **每个个体维护两类关系**：
   - `lastZoo`：最后一次逛动物园的伙伴编号（巧克力生日邀请用）。每次逛动物园双方都更新自己的 `lastZoo`。
   - `mallPartners`：`std::set<int>`，曾一起逛商场的伙伴集合（草莓生日邀请用）。每次逛商场**双方互相 insert**（任意类型都记）。
3. **逛动物园** `zooWith(other)`：巧克力 +5；草莓 +1，同伴是巧克力再 +5。同时 `lastZoo = other.id`。
4. **逛商场** `mallWith(otherId, other)`：巧克力 +1；草莓 +5，同伴巧克力再 +5。双方 `mallPartners.insert(对方)`。
5. **过生日**：
   - 巧克力：+1；若 `lastZoo != -1` 再 +5 并邀请该编号（被邀请者 +1）。
   - 草莓：+|mallPartners|；对集合中每个来宾 +1。
6. 主循环按 op 分派，op2 后对被邀请者调用 `beInvited()`。

### ③ 完整代码框架
```cpp
// ============ strawchoco.h ============
#pragma once
#include <set>

class StrawChoco {
protected:
    long mood = 0;
    int  lastZoo = -1;                 // 最后一次逛动物园的伙伴（巧克力生日邀请）
    std::set<int> mall;                // 曾一起逛商场的伙伴（草莓生日邀请）
public:
    virtual ~StrawChoco() {}
    virtual bool isStraw() const = 0;  // 区分草莓/巧克力

    void zoo(int selfId, int otherId, const StrawChoco& other) {     // 逛动物园（自己视角）
        if (!isStraw()) mood += 5;                                    // 巧克力
        else { mood += 1; if (!other.isStraw()) mood += 5; }         // 草莓(+同伴巧克力额外5)
        lastZoo = otherId;
    }
    void mall(int selfId, int otherId, const StrawChoco& other) {    // 逛商场（自己视角）
        if (!isStraw()) mood += 1;
        else { mood += 5; if (!other.isStraw()) mood += 5; }
        (void)selfId;
        this->mall.insert(otherId);                                   // 任意类型都互记
    }
    void beInvited() { mood += 1; }                                   // 被邀请一律 +1

    // 返回被邀请者编号集合（由主循环对每个调用 beInvited）
    const std::set<int>& birthdayInvited() const { return mall; }
    int  lastZooPartner() const { return lastZoo; }
    long getMood() const { return mood; }
};

struct Chocolate : StrawChoco { bool isStraw() const override { return false; } };
struct Strawberry : StrawChoco { bool isStraw() const override { return true; } };
```

## 扣分重灾区
1. **提交格式**：zip 根目录直接放文件（**不要套子文件夹**）；**不提交 main.cpp / Makefile**。
2. **模板分离编译**：模板实现必须放头文件（或被 include 的 .cpp）；2023 直线相交 main 直接 `#include "*.cpp"`。
3. **输出逐字符**：`can't undo`（无句点）vs `Books Checked out X.`（有句点）vs SCREEN 的 `*` 位置 vs `<<` 最后无回车——**一律以样例为准**。
4. **浮点 eps**：`fabs(a-b)<1e-6`，别直接 `==`。
5. **undo 是否记录无变化操作**：GUI 是"无论是否改变都记录"，务必读清题意。
6. **智能指针 vs 栈对象**：计算图 LeafNode 是栈对象，`shared_ptr` 必须**空 deleter**。
7. **const 正确性 + 引用返回**：`get/operator[]` 返回 `T&`，const 版返回 `const T&`；多维 `[]` 需两套。
8. **共享状态用引用成员**：软件团队 `codes` 必须 `string&`。
