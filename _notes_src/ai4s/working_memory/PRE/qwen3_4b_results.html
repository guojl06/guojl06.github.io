7. 综合结论

cred<gold ≈ 80% 跨规模一致
0.6B / 4B / 671B 均相同——slot-level PI 是 content-addressable retrieval 的结构性结果。
4B overall weaker
batch 模式 acc 偏低 (17-43%)
equal 条件崩溃 (7-17%)
3x3 AB C1_un 完全遗忘 (60%→0%)
PI Release: 跨模型一致的 null result
同槽位：场景标签无法隔离 → cross 67-93%
正交槽位：Cross=0 但 dual-task cost 显著
3x3+双案：共享槽位 cross=67%，独特槽位 AB→0%
​LLM 没有 category-based memory organization。
