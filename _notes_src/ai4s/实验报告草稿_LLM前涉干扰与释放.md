## 一、认知心理学背景概述

**前瞻干扰（Proactive Interference, PI）**是记忆研究的核心现象之一：先前学习并保持的信息会干扰对新信息的编码与提取。在连续更新的任务流中，旧值与竞争性新值共存，导致提取错误率随更新次数上升——这与人类"旧电话号码干扰新号码"的记忆失败模式同构。

**释放自前瞻干扰（Release from PI）**由 Wickens (1970) 经典范式确立：被试连续对同一语义类别（如水果）的词做短暂记忆任务，性能随 trial 递减（PI 累积）；当中途切换到新类别（如交通工具）时，性能立即回升——即"释放"。Wickens 系统测量了 12 对语义类别间的**释放量 RPI**，发现它与类别间的语义重叠度单调相关：重叠越大（如动词→形容词，RPI=0.01）释放越小，差异越大（如文字→数字，RPI=0.94）释放越接近完全。这说明人类的 PI 建立在**语义类别的编码**之上，释放的幅度由表征空间的几何结构决定。

**工作记忆与 n-back**：n-back 任务要求判断当前刺激与 n 步前刺激是否相同，是测量工作记忆更新与干扰控制的标准范式（Baddeley 工作记忆模型中的中央执行功能）。在 n-back 流中持续呈现同一类别刺激同样会累积 PI。

**LLM 视角**：大语言模型的上下文窗口可视为其"工作记忆"，KV cache 中不存在主动遗忘机制——所有历史 token 的表征都保留并参与注意力分配，因此理论上 LLM 应表现出比人类更强的 PI。另一方面，LLM 的"提取"完全依赖注意力机制对旧 token 的重加权，这为通过 prompt 干预（改变上下文结构）人为"释放"干扰提供了人类被试不具备的操作空间。本实验因此包含两个互补问题：(1) 干预能否释放 LLM 的 PI、何时有效（范式一）；(2) LLM 的 PI 是否像人类一样由语义类别结构驱动（范式二）。

## 二、实验范式设计、设计理由与预期结果

### 范式一：PI 流 + 11 组 prompt 干预（pi_release 模块）

**范式**：向模型一次性输入一条 key-value 更新流（如 `key1: apple; key2: dog; key1: orange; ...`），每个 key 被反复覆盖多次，读完后要求回答每个 key 的**最新值**。基线正确率随覆盖次数（干扰负载）下降，构成 PI 的操作化测量。

**干预组**（G0=基线，G1–G9 为干预）：

| 组 | 操作 | 心理学/机制动机 |
|---|---|---|
| G1 | "Ignore all prior values" 语义指令 | 指令能否直接压制干扰（"知道"≠"做到"检验） |
| G2 | 伪造 User→Assistant→User 对话回合 | 利用对话结构制造"新回合"边界 |
| G3 | 符号墙 `};}}}---===` | 句法层面的断崖 |
| G4 | glitch token（.SolidGoldMagikarp 等高范数罕见 token） | 高能量 token 作为注意力锚点 |
| G5 | 零宽字符 / RTL override 等字节级扰动 | 字节层面破坏连续性 |
| G6 | 要求模型先自生成 20 个乱码 token | 自生成干扰对照 |
| G7 | "Focus ONLY on the LAST occurrence" | recency 锚定指令 |
| **G8s** | **中段注入伪造对话（含过期快照）+ 新任务边界** | 忠实复刻 arXiv:2506.08184 的 hackreset |
| G8/G9 | 末尾注入正确/错误答案 | 天花板/地板作弊对照 |

**设计理由**：(a) G8s 的注入值取**注入点处的快照**（相对最终查询多数已过期），模型无法靠抄写答案得分，因此是对"任务边界"机制本身的诚实检验；(b) 单一干预与堆叠干预（如 G2+G4+G3+G8s）并存，可检验干预间是替代还是协同；(c) 通过改变每 key 更新次数（3→97）构造干扰负载的**剂量-反应曲线**。

**预期结果**：基于 PI 理论，预期基线正确率随负载单调下降；干预在高负载（干扰大）时有效、低负载（干扰小）时因引入额外噪声而可能有害——即干预效果与负载存在交互。

### 范式二：n-back × 类别切换（recall_rating 模块）

**范式**：n=2 语义 n-back，序列前半段为类别 A 的词、中段切换到类别 B（exp 条件）；对照条件全程类别 A 不切换（ctrl）。12 个词对采用 Wickens (1970) 原表（Mewhort et al. 2018 整理），每个词对附带人类 RPI 常模（0.01–0.94）。每条件 50 trial，deepseek-chat，逐轮多轮对话。另设 rating 条件测量逐词评分的序列依赖。

**设计理由**：这是把人类 PI-release 范式**原封不动**移植到 LLM：人类 RPI 常模已有，若 LLM 的释放幅度与人类 RPI 相关，则说明 LLM 与人类共享"语义几何决定干扰"的规律；若无关，则说明 LLM 的干扰机制在性质上不同。这是一个无论结果如何都有信息量的强检验。

**预期结果**：若 LLM 像人类，exp 条件切换后性能回升幅度应随各词对的 RPI 单调变化（VA≈0，WN≈大）；对照 ctrl 条件应持续衰减。

## 三、实验流程与结果分析

### 流程

1. PsyST Lab 平台：模块化设计，BaseModule 定义条件/任务/评分接口，实验自动注册到仪表板，结果落盘 runs/<module>/<tag>/（results.jsonl + summary.json）。
2. 评分：逐字移植论文（arXiv:2506.08184）的答案抽取与判分正则，保证与文献数字直接可比。
3. 负载扫描：每 key 更新次数 n ∈ {3, 6, 12, 24, 48, 97}，46 个 key，n=10/条件；n-back 每条件 50 trial。

### 结果一：基线随干扰负载崩塌（PI 成立）

qwen3-4b-2507 基线（G0）正确率：u3=1.00 → u6=0.74 → u12=0.42 → u24=0.15 → u48=0.01 → u97=0.04；qwen3.5-2b 类似（0.76→0.00）。**LLM 存在强 PI，且小容量模型崩塌更早**。

### 结果二：干预效果存在负载交叉点（剂量-反应）

| updates | qwen3-4b: G0→G8s (Δ) | qwen3.5-2b: G0→G8s (Δ) |
|---|---|---|
| 3 | 1.00→0.72 (**−0.28**) | 0.76→0.73 (−0.03) |
| 6 | 0.74→0.20 (**−0.54**) | 0.30→0.41 (**+0.11**) |
| 12 | 0.42→0.28 (−0.14) | 0.21→0.35 (+0.14) |
| 24 | 0.15→0.51 (**+0.36**) | 0.06→0.45 (**+0.39**) |
| 48 | 0.01→0.62 (**+0.61**) | 0.00→0.45 (**+0.45**) |
| 97 | 0.04→0.60 (**+0.56**) | 0.00→0.56 (**+0.56**) |

**核心发现：G8s 干预效果从"有害"到"有效"存在交叉点**：qwen3-4b 的交叉点位于 n∈(12,24)，qwen3.5-2b 位于 n∈(3,6)——**容量越小的模型交叉点越早**。deepseek-chat 上的堆叠实验同样支持：低负载（46×100）时单独干预几乎全部有害（G1 −0.12、G2 −0.19、G6 −0.27），仅 G2+G8s 组合有效（+0.14）；高负载（46×400，基线 0.391）时 G8s 单独 +0.12，最强组合 G2+G4+G3+G8s 达 **+0.275**（0.666）。另发现 **G4 的破坏性反转**：低负载时 glitch token 有害（0.631 < 基线 0.653），高负载时转为促进（组合内 +0.24）——低负载时是噪声，高负载时成为注意力锚点。作弊对照验证量表有效性：G8=1.000，G9=0.258。

### 结果三：LLM 有释放效应、但幅度不随语义距离调制（与人类质的不同）

n-back 12 个词对中，切换条件（exp）第二段准确率 0.68–0.79，而不切换对照（ctrl）第二段全部塌至 0.0——**切换类别带来 ~0.65–0.79 的大幅释放，LLM 确有 PI 释放**。但关键在调制规律：人类 RPI=0.01 的 VA 词对释放 0.68，人类 RPI=0.94 的 WN 词对释放 0.62，12 个词对的释放量在 0.62–0.77 间几乎恒定，**与人类 RPI 无相关**（人类预期：VA 应几乎无释放、WN 应几乎全释放）。信号检测指标：d' 1.18–2.26，虚报率稳定 ≤7%，排除反应偏向混淆。

**结论：LLM 的释放是"边界驱动"而非"语义驱动"**——任何任务流的中断/切换都释放干扰，与切换前后语义距离无关；人类则是语义重构驱动（Wickens 几何）。这是 LLM 与人类 PI 机制的一个清晰的定性分歧。

## 四、机制性解释（加分项 1）

1. **PI 的机制**：LLM 回答"最新值"依赖注意力在同名 key 的多次出现间做 soft 选择；旧值残留在 KV cache 中持续竞争，且流越长注意力越稀释，两重因素叠加导致基线随 n 崩塌（对应结果一）。
2. **G8s 为何有效**：伪造对话边界使模型把边界之前的内容当作"已封闭任务"整体抑制，注意力质量重新集中于尾部批次——本质是**给没有遗忘机制的存储系统外挂了一个"划分检查点"**。注入的过期快照并非信息来源（多数已过期），边界才是有效成分。
3. **为何低负载有害**：边界重置是有代价的操作（注入文本本身是干扰、过期快照有误导风险），干扰尚未积累时成本 > 收益（对应结果二交叉点，判据见第五节）。
4. **G1 无效与 G4 反转**：语义指令（G1）不改变注意力的实际分配，模型"知道"要求但执行机制不变——knowing-doing gap 的架构根源；glitch token（G4）在高范数位置形成注意力汇聚点，低负载时表现为纯噪声，高负载时恰好与 G8s 边界协同切断前文连续性。
5. **n-back 的非类人调制**：LLM 判断 2-back 匹配依赖对 t−2 位置 token 的逐字检索，类别身份不进入决策通路；切换收益来自流结构的中断（分布变化/边界效应），而非把新类别编码进新语义上下文。人类释放依赖上下文重构（新类别 = 新编码空间），故受重叠度调制；LLM 无此编码环节，故释放量恒定。

## 五、Toy Model 与数学判据（加分项 2）

### 5.1 干扰累积 × 边界重置模型（范式一）

设每个 key 被更新 n 次，流总长 L=K·n。模型对"当前值"的判断是同名 key 各次出现的 softmax 选择。定义**累积干扰质量**：

    I(n) = I∞ · (1 − e^(−n/n₀))

（旧值随 recency 衰减但被稀释部分抵消，净效果为有界单调增；I∞ 为饱和值，n₀ 为积累尺度。）

基线正确率 P0(n) = 1/(1+I(n))。干预（边界重置，强度 λ∈[0,1]）以比例 λ 清除既有干扰，但引入固定代价 c（注入噪声与过期快照的误导率）：P1(n) = (1−c) / (1+(1−λ)·I(n))。净效应 Δ(n) = P1−P0，一阶展开后分子 ∝ λ·I(n) − c·(1+I(n))。

**数学判据：干预产生正释放 ⟺ λ > c 且 I(n) > c/(λ−c)。**

由 I(n) 单调增可得唯一交叉点：

    n* = −n₀ · ln( 1 − c / ((λ−c)·I∞) )    （要求 λ>c，否则任何负载下 Δ≤0）

**模型预测与数据对照**：
1. 交叉点必然存在，分割"有害区/有效区"——与两个模型的实测交叉一致；
2. 小容量模型更易被稀释淹没 → I∞ 更小、n₀ 更小 → **n\* 更小**——预测"容量越小交叉越早"，实测 qwen3.5-2b n*∈(3,6) 早于 qwen3-4b 的 n*∈(12,24)，方向一致；
3. λ→1、c→0（G8 答案注入）应全程有效——与 G8=1.00 一致；纯代价无重置（G6 自生成乱码）λ≈0 应全程有害——与 G6=0.384 一致。

### 5.2 释放调制的判别模型（范式二）

设释放量 R = R_max·(δ·D_w) − ε，D_w 为词对语义距离（与人类 RPI 正相关），δ 为"语义重构增益"：

- 人类机制：δ_H > 0 → R 与 RPI **显著正相关**；
- 边界机制：δ ≈ 0 → R ≈ 常数，与 RPI **零相关**，且只要 ctrl 塌零则 R 显著 > 0。

实测：R = 0.62–0.77（显著大于 0，ctrl=0），R 对 RPI 的斜率 ≈ 0。**判别结果：LLM 属于边界机制（δ≈0），与人类（δ_H>0）定性分离。**

## 六、总结与局限

本实验在自研平台上完成了 LLM 前瞻干扰的两条互补测量：(1) PI 在 LLM 上真实存在且比人类更严重，但可以通过任务边界干预"释放"，干预有效性服从可推导的剂量-反应判据（存在交叉点 n*，其位置随模型容量系统变化）；(2) LLM 的释放机制与人类在"语义调制"维度上定性不同——边界驱动而非语义几何驱动。局限：负载扫描的 n=10/条件较小；toy model 参数（λ, c, n₀）尚未用多模型数据系统拟合；n-back 仅 n=2 单一负载。未来工作：提取各模型对干预 token 的注意力权重直接检验"锚点"假说；用 LLM embedding 距离替换人类 RPI 常模，检验"同一几何、不同增益"的量化版本。
