## 2026.3.4
1. 内存是用 ```0x2345``` 的 16 进制表示的。
2.
| 数据类型 | 字节数 (Bytes) | 位数 (Bits) | 数值范围 (Range) | 常用宏定义 / 极限值 |
| :--- | :---: | :---: | :--- | :--- |
| **bool** | 1 | 8 | `true` 或 `false` | - |
| **char** | 1 | 8 | -128 到 127 | `CHAR_MIN` / `CHAR_MAX` |
| **unsigned char** | 1 | 8 | 0 到 255 | `UCHAR_MAX` |
| **short** | 2 | 16 | -32,768 到 32,767 | `SHRT_MIN` / `SHRT_MAX` |
| **unsigned short** | 2 | 16 | 0 到 65,535 | `USHRT_MAX` |
| **int** | 4 | 32 | -2,147,483,648 到 2,147,483,647 | `INT_MIN` / `INT_MAX` |
| **unsigned int** | 4 | 32 | 0 到 4,294,967,295 | `UINT_MAX` |
| **long** | 8 | 64 | 约 ±9.22 × 10¹⁸ | `LONG_MIN` / `LONG_MAX` |
| **unsigned long** | 8 | 64 | 0 到 1.84 × 10¹⁹ | `ULONG_MAX` |
| **long long** | 8 | 64 | 约 ±9.22 × 10¹⁸ | `LLONG_MIN` / `LLONG_MAX` |
| **unsigned long long** | 8 | 64 | 0 到 1.84 × 10¹⁹ | `ULLONG_MAX` |
| **float** | 4 | 32 | ±1.17 × 10⁻³⁸ 到 ±3.40 × 10³⁸ | `FLT_MIN` / `FLT_MAX` |
| **double** | 8 | 64 | ±2.22 × 10⁻³⁰⁸ 到 ±1.79 × 10³⁰⁸ | `DBL_MIN` / `DBL_MAX` |
| **long double** | 16 | 128 | 精度更高，范围因编译器而异 | `LDBL_MIN` / `LDBL_MAX` |
| **size_t** | 8 | 64 | 0 到 1.84 × 10¹⁹ (用于表示内存大小) | `SIZE_MAX` |

3. 记住 ```string``` 类型有多一个终止符。
