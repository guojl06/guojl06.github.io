# Amari-Hopfield 网络笔记

## 0. 这是什么

Hopfield 网络是一种**联想记忆模型**——给定一个残缺或带噪的模式，它能自动收敛到最接近的存储模式。和"按地址取数据"的普通内存不同，它是**按内容寻址**的：给一部分线索，能想起整张图。

它的物理原型是 **Ising 模型**（自旋玻璃）：每个神经元是一个 ±1 的自旋，权重 Wᵢⱼ 是自旋间的耦合，存图过程相当于按 Hebb 规则设定耦合，让目标模式成为低能态。

> **核心思想一句话**：存图 = 用 Hebb 规则让目标模式成为能量极小；恢复 = 沿能量梯度下降到最近的极小点。

## 2. 存图：Hebb 规则

$$W = \frac{1}{d}\sum_{\mu=1}^{d} x^{(\mu)} \, x^{(\mu)\top}$$

对每张图 x⁽ᵖ⁾（784 维向量）做外积，得到 784×784 矩阵，全部累加。

**外积 `xᵢ·xⱼ` 编码的是"像素 i 和 j 在这张图里是否一致"**：两像素同号 → +1（兴奋连接），反号 → −1（抑制连接）。这正是 Hebb 规则——"一起放电的神经元连在一起"。权重矩阵 W 就是所有模式像素共现关系的叠加。

两个工程细节：

- **对角线清零** `np.fill_diagonal(W, 0)`：神经元不连自己，否则会自我强化破坏动力学
- **除以 d**：归一化。由于恢复时取 sign，正比缩放不影响结果，只影响能量的数值大小

## 3. 恢复：异步更新

### 更新规则

```
xᵢ ← sign( hᵢ − θ ),    hᵢ = Σⱼ Wᵢⱼ xⱼ   (局部场)
```

每步随机挑一个像素 i，由**其它所有像素的加权输入** hᵢ 决定它的新值。Wᵢⱼ > 0 表示 j 把 i 往同号方向拉，<0 则推开。sign 把连续量压回 ±1。

### 为什么能想起原图

把存规则代入局部场，得到一个有启发性的形式：

$$h_i = \frac{1}{d}\sum_{\mu} x_i^{(\mu)} \cdot \underbrace{\bigl(x^{(\mu)} \cdot x\bigr)}_{\text{输入与模式 } \mu \text{ 的相似度}}$$

**输入离哪个存储模式最近，局部场就被那个模式主导**。具体说，输入接近 x⁽¹⁾ 时：

$$h_i \approx \underbrace{\tfrac{N}{d}\, x_i^{(1)}}_{\text{信号（主项）}} + \underbrace{\tfrac{1}{d}\sum_{\mu\neq 1} x_i^{(\mu)}(x^{(\mu)}\!\cdot x)}_{\text{串扰（噪声）}}$$

信号项把 xᵢ 推向 xᵢ⁽¹⁾，串扰项平均盖不过主项，于是 `sign(hᵢ) ≈ xᵢ⁽¹⁾`，像素被纠正回原图。

### 容量上限

串扰噪声方差按 √(d/N) 增长，信噪比 ≈ √(N/d)。严格分析给出：

$$d_{\max} \approx 0.138\,N$$

N=784 时约 108 张图。**超过这个数，所有模式的串扰同时放大，所有记忆一起坏掉**——这是 Hopfield 网络最经典的相变现象。

### 为什么必须异步

异步 = 一次只翻一个像素，下一个立刻看到新值。这是第 4 节能量单调下降证明的前提。如果所有像素同时按上一轮状态翻转（同步更新），可能产生 2-周期极限环永远不收敛。**异步不是工程选择，是数学要求。**

## 4. 能量函数

### 形式

$$E(x) = -\tfrac{1}{2}\sum_{i,j} W_{ij}\, x_i x_j + \sum_i \theta_i x_i$$

这就是 **Ising 模型的哈密顿量**：xᵢ 是自旋，Wᵢⱼ 是耦合，θᵢ 是外场（本脚本 θ=0，可忽略）。Hopfield 的关键洞察：**联想记忆 = 工程化的 Ising 系统**。负号让"对齐"对应低能；½ 是因为 (i,j) 和 (j,i) 在双重求和里计了两次。

### 能量在衡量什么

把求和拆成一对一对像素来看，每对贡献 `−Wᵢⱼ·xᵢ·xⱼ`：

| 学习时记下的关系 | 现在实际取值 | 贡献 | 状态 |
|---|---|---|---|
| Wᵢⱼ > 0（该同号） | xᵢ = xⱼ | 负 | ✓ 满意 |
| Wᵢⱼ > 0（该同号） | xᵢ ≠ xⱼ | 正 | ✗ 挫折 |
| Wᵢⱼ < 0（该反号） | xᵢ ≠ xⱼ | 负 | ✓ 满意 |
| Wᵢⱼ < 0（该反号） | xᵢ = xⱼ | 正 | ✗ 挫折 |

> **E = 当前状态违反了多少条学到的像素关系**。被违反的关系在物理上叫 **frustration（挫折）**。完好的存储图所有关系都对齐 → E 最低；涂花的图一堆关系被违反 → E 高。

### 为什么只降不升

更新规则不是随便定的——**它就是为下降而设计的**。注意 `hᵢ = Σⱼ Wᵢⱼ xⱼ` 正好是 E 对 xᵢ 的负梯度：

$$\frac{\partial E}{\partial x_i} = -\sum_j W_{ij} x_j = -h_i$$

所以 `xᵢ ← sign(hᵢ − θ)` 等价于"翻向能让自己的能量项更低的那一边"，本质是**离散化的梯度下降**。

形式化推导：更新 i 时只有含 xᵢ 的能量项变化，利用 W 对称可化简为 `−xᵢ(hᵢ − θᵢ)`，于是

$$\Delta E = -(x_i' - x_i)(h_i - \theta_i)$$

而 `xᵢ' = sign(hᵢ − θᵢ)` 保证了 `(xᵢ' − xᵢ)` 与 `(hᵢ − θᵢ)` **要么同号要么有一个为零**（不需要翻时差为零）。两种情况都给出 **ΔE ≤ 0**。

状态空间有限（2^N 种构型），E 有下界，单调不增的序列必然有限步内停在不动点。**这就是收敛的全部证明。**

### 极小点 = 存储图 = 吸引子

代入存储图 x⁽¹⁾：hᵢ ≈ (N/d)·xᵢ⁽¹⁾，sign 后仍是 xᵢ⁽¹⁾，所以它是**不动点**。从它翻转任一像素 i 都会使 ΔE > 0（因为 (hᵢ − θᵢ) 与 xᵢ⁽¹⁾ 同号），所以它的所有邻居能量都更高 → **局部极小**。

从某个初始状态出发、最终收敛到同一个吸引子的所有初始状态集合，构成该模式的**吸引盆**（basin of attraction）。脚本实验 3 的输入是 image1 和 image2 的交集，同时沾边两个模式，恰好落在两个吸引盆的**分水岭**上，最终落到哪边由噪声扰动决定。
