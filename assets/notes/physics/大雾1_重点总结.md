## 🎯 大雾1 小测重点速览

---

### 一、运动学核心

**基本定义：**
$v = \frac{dx}{dt}, \quad a = \frac{dv}{dt} = \frac{d^2x}{dt^2}$

**重要公式：**
$v^2 - v_0^2 = 2a(x - x_0)$

**圆周运动：**
- 线速度大小：$|v| = \omega R$
- 向心加速度：$|a| = \omega^2 R$

**极坐标（重点！）：**
速度：$\vec{v} = \frac{dr}{dt}\vec{e}_r + \omega r \vec{e}_\theta$

加速度：$\vec{a} = \left(\frac{d^2r}{dt^2} - \omega^2 r\right)\vec{e}_r + \left(r\frac{d\omega}{dt} + 2\omega\frac{dr}{dt}\right)\vec{e}_\theta$

---

### 二、非惯性系 ⭐常考

**加速度变换：**
$\vec{a}' = \vec{a} - \vec{a}_{O'}$

**旋转系中的惯性力：**
- **离心力：** $m\omega^2 r$（方向向外）
- **科里奥利力：** $2m\vec{v}' \times \vec{\omega}$（方向由 $\vec{\omega} \times \vec{v}$ 决定）

记忆口诀：中心→边缘，力向后；边缘→中心，力向前

---

### 三、动量与角动量 ⭐核心

**质心：**
$\vec{r}_c = \frac{\sum m_i \vec{r}_i}{\sum m_i}$

**关键结论：**内力抵消！
$M\vec{a}_c = \sum \vec{F}_{\text{外}}$（欧拉动量第一定律）

**动量守恒：**
$\sum \vec{F}_i = 0 \Rightarrow \sum \vec{p}_i = \text{常量}$

**火箭方程：**
$v = u \ln\frac{M_0}{M_f}$

**角动量：**
$\vec{L} = \vec{r} \times \vec{p} = \vec{r} \times m\vec{v}$

圆周运动：$|L| = m\omega r^2$

力矩：$\vec{\tau} = \vec{r} \times \vec{F} = \frac{d\vec{L}}{dt}$

**守恒条件：** $\sum \vec{\tau}_{\text{外}} = 0 \Rightarrow \vec{L} = \text{常量}$

**圆锥摆（经典题）：**
$\cos\theta = \frac{g}{\omega^2 l}$

---

### 四、定轴转动碰撞 ⭐易错点

**结论：角动量守恒，但线动量不守恒！**

原因：支点 $O$ 产生瞬时冲量

碰撞前：$P_{\text{before}} = m_2 v_0$

碰撞后：$P_{\text{after}} = \frac{m_2 + 2m_1}{m_2 + 4m_1} m_2 v_0 < P_{\text{before}}$

---

### 五、跷跷板（能量法）

$\omega_0 = \frac{2}{l}\sqrt{\frac{(m_1 - m_2)gh}{m_1 + m_2}}$

### 🔥 考前必看提醒

1. **纯滚动条件**：$v_0 = \omega R$（底部点速度为零）

3. **潮汐力**：近日/远日侧向外拉伸，侧面向内压缩
