# 斐波那契数列

## 题目描述

斐波那契数列 f(n) 定义如下：

* f(0) = 1
* f(1) = 1
* f(n) = f(n - 1) + f(n - 2)，其中 n >= 2

---

## 输入

第一行包含一个整数 T，表示测试用例的数量。

接下来 T 行，每行包含一个整数 n。

0 <= n <= 80

1 <= T <= 5000

**注意：** 请注意本题的数据范围。

---

## 输出

对于每个输入，输出斐波那契数列第 n 项的值，即 f(n)。

---

## 样例输入

```
2
44
77
```

---

## 样例输出

```
1134903170
8944394323791464
```
