# 第 k 小的数

## 题目描述

给定一个整数数组 $(a\_0, a\_1, \cdots, a\_{n-1})$，找出数组中第 $k$ 小的数。

## 输入

第一行包含两个整数 $n$ 和 $k$，其中：

* $1 \leq n \leq 5000$
* $1 \leq k \leq n$

第二行包含 $n$ 个整数，每个整数的范围为 $[1, 5000]$。

## 输出

输出数组中第 $k$ 小的数。

## 样例输入

```
4 2
1 2 3 4
```

## 样例输出

```
2
```

## 提示

你可以使用 C++ 中的 `std::sort` 或 `std::nth_element`。

如果你不熟悉它们，可以上网搜索使用方法。
